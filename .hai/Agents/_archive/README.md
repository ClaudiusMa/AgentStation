Use this directory for older planning snapshots, retired handoffs, or session summaries that are no longer active but may still be worth keeping for historical reference.

Archive groups:

- [`handoffs/`](handoffs/) — retired dated baton passes, design handoffs, and reviews.
- [`tasks/`](tasks/) — delivered or superseded worker queues.
- Dated planner snapshots may live directly in `_archive/` when preserving the old plan materially helps future work.

Keep the active harness lean. Move bulk history here instead of letting live docs accumulate stale state.
